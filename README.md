# Little Talkers 🌈

A gentle, mobile-friendly English-speaking playground for a young child who understands basic English and is building confidence using short phrases.

## The games

1. **Story Time** — Teddy and Bunny have little problems and adventures. The child can suggest what happens next in her own words. There is no single correct answer.
2. **Everyday English** — learn a whole collection of practical phrases first, one after another. After the learning sequence, match each everyday situation to a useful phrase. Then have a go at saying it, with a final round that removes the displayed model.
3. **More games soon** — space is reserved for a third game concept. It has deliberately not been filled with a duplicate of the first two.

## Design principles

- Playful, relaxed and never a test.
- Encourage short phrases and simple sentences without demanding perfect grammar.
- Give the child time to think and respond.
- Speech recognition is optional; the activities still work without it.
- Use the sound toggle and Listen again button to control spoken prompts.

## Publish on GitHub Pages

1. Open the repository's **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then click **Save**.
4. Wait for deployment. The URL will look like `https://YOUR-USERNAME.github.io/English-game/`.

## Browser notes

- Text-to-speech uses an English voice when one is available on the device.
- Speech recognition is not supported in every browser and may mishear young children's voices. It is a playful optional aid, not an assessment.
- An adult should supervise microphone permission and use.
- The website does not save speech transcripts.
